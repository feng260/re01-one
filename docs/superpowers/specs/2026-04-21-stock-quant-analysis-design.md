# 股票量化分析工具设计文档

## 1. 项目概述

本工具旨在筛选出近期涨势最好的股票，通过多维度分层筛选的方式，从A股市场中识别出具有良好上涨潜力的股票。工具将基于5-10日的短期分析周期，使用公开API获取数据，并通过网页界面展示筛选结果和分析依据。

## 2. 核心功能

### 2.1 分析维度

工具将从以下6大维度进行分析：

1. **短期涨幅**：衡量股票在近期的价格上涨幅度
2. **趋势强度**：评估股票价格走势的强度和持续性
3. **量价配合**：分析成交量与价格变动的配合情况
4. **资金流向**：监测资金的流入流出情况
5. **行业热度**：评估股票所属行业的整体表现
6. **风险控制**：衡量股票的风险水平

### 2.2 量化标准

#### 2.2.1 短期涨幅
- **计算方法**：(当前价格 - 10日前价格) / 10日前价格 * 100%
- **筛选标准**：涨幅大于10%

#### 2.2.2 趋势强度
- **计算方法**：
  - 5日均线与10日均线的金叉状态
  - 价格是否持续站在5日均线上方
  - 短期均线斜率
- **筛选标准**：
  - 5日均线 > 10日均线
  - 最近5个交易日中有4个交易日收盘价在5日均线上方
  - 5日均线斜率为正

#### 2.2.3 量价配合
- **计算方法**：
  - 成交量放大倍数（与前5日平均成交量相比）
  - 价格上涨时的成交量是否大于价格下跌时的成交量
- **筛选标准**：
  - 最近5日平均成交量比前5日平均成交量放大至少30%
  - 价格上涨日的平均成交量大于价格下跌日的平均成交量

#### 2.2.4 资金流向
- **计算方法**：
  - 大单资金净流入（超大单+大单买入金额 - 超大单+大单卖出金额）
  - 资金净流入率
- **筛选标准**：
  - 最近3个交易日资金净流入
  - 资金净流入率大于5%

#### 2.2.5 行业热度
- **计算方法**：
  - 行业指数涨幅（与10日前相比）
  - 行业内上涨股票数量占比
- **筛选标准**：
  - 行业指数涨幅大于8%
  - 行业内上涨股票数量占比大于60%

#### 2.2.6 风险控制
- **计算方法**：
  - 波动率（最近10日标准差）
  - 最大回撤（最近10日）
  - 夏普比率
- **筛选标准**：
  - 波动率小于同期沪深300指数波动率的1.5倍
  - 最大回撤小于15%
  - 夏普比率大于0.5

## 3. 筛选流程

采用多维度分层筛选的方式，具体流程如下：

1. **第一层筛选**：短期涨幅 > 10%
2. **第二层筛选**：趋势强度符合标准
3. **第三层筛选**：量价配合符合标准
4. **第四层筛选**：资金流向符合标准
5. **第五层筛选**：行业热度符合标准
6. **第六层筛选**：风险控制符合标准

经过以上6层筛选后，剩余的股票即为涨势最好的股票。

## 4. 数据来源

使用以下公开API获取数据：

1. **新浪财经API**：获取股票基本信息、历史价格、成交量等数据
2. **东方财富API**：获取资金流向、行业数据等信息
3. **同花顺API**：获取技术指标数据

## 5. 输出格式

### 5.1 网页界面设计

1. **筛选结果列表**：
   - 股票代码、股票名称
   - 短期涨幅
   - 综合评分
   - 详细分析按钮

2. **详细分析页面**：
   - 股票基本信息
   - 6大维度的具体分析数据和图表
   - 风险提示
   - 历史走势图表

3. **筛选参数设置**：
   - 分析周期调整
   - 各维度筛选标准调整
   - 行业筛选

### 5.2 数据展示

- **表格形式**：展示筛选结果的详细数据
- **图表形式**：展示股票的价格走势、成交量变化等
- **热力图**：展示行业热度分布

## 6. 风险提示

对于筛选出的股票，工具将提供以下风险提示：

1. **短期涨幅过大风险**：短期涨幅过大的股票可能面临回调风险
2. **成交量异常风险**：成交量突然放大可能是短期资金炒作的结果
3. **行业轮动风险**：行业热度可能随时变化
4. **市场系统性风险**：大盘波动可能影响个股表现
5. **信息不对称风险**：公开数据可能存在延迟或不准确

## 7. 技术实现

### 7.1 技术栈

- **前端**：HTML、CSS、JavaScript、ECharts（图表库）
- **后端**：Python、Flask（Web框架）
- **数据处理**：Pandas、NumPy
- **API调用**：Requests库

### 7.2 架构设计

1. **数据采集模块**：负责从公开API获取股票数据
2. **数据处理模块**：负责计算各项指标和筛选股票
3. **Web服务模块**：提供网页界面和数据接口
4. **可视化模块**：负责生成图表和数据展示

### 7.3 数据流

1. 定时从API获取最新股票数据
2. 计算各项指标并进行分层筛选
3. 生成筛选结果和分析报告
4. 通过网页界面展示给用户

## 8. 性能优化

1. **数据缓存**：缓存API返回的数据，减少重复请求
2. **并行计算**：使用多线程处理大量股票数据
3. **增量更新**：只更新最新数据，减少计算量
4. **分页加载**：分页展示筛选结果，提高页面加载速度

## 9. 扩展性

1. **指标扩展**：可添加更多技术指标和基本面指标
2. **数据源扩展**：可接入更多数据源，提高数据质量
3. **策略扩展**：可添加不同的筛选策略，适应不同市场环境
4. **用户定制**：可允许用户保存个性化筛选参数

## 10. 总结

本工具通过多维度分层筛选的方式，从A股市场中识别出近期涨势最好的股票。工具采用量化标准，确保筛选结果的客观性和可重复性。通过网页界面展示筛选结果和分析依据，并提供风险提示，帮助用户做出更明智的投资决策。

工具设计贴合A股市场规则，适配日线/周线数据，可根据用户需求调整分析周期和筛选标准。使用公开API获取数据，降低了使用成本，同时保证了数据的及时性和准确性。
