# 股票量化分析工具

## 项目简介

本工具旨在筛选出近期涨势最好的股票，通过多维度分层筛选的方式，从A股市场中识别出具有良好上涨潜力的股票。

## 核心功能

- **多维度分析**：从短期涨幅、趋势强度、量价配合、资金流向、行业热度、风险控制6大维度进行分析
- **量化标准**：采用可量化、可计算的标准，确保筛选结果的客观性和可重复性
- **实时数据**：从公开API获取最新股票数据，保证数据的及时性和准确性
- **可视化展示**：通过图表直观展示股票价格走势和成交量变化
- **风险提示**：为筛选出的股票提供详细的风险提示

## 技术架构

- **前端**：HTML、CSS、JavaScript、ECharts（图表库）
- **后端**：Python、Flask（Web框架）
- **数据处理**：Pandas、NumPy
- **API调用**：Requests库


   ```bash

   ```

   打开浏览器，访问 http://127.0.0.1:5000

## 使用方法

1. **输入股票代码**

   在文本框中输入要分析的股票代码，多个代码用逗号分隔。例如：
   ```
   sh600519,sz000858,sh601318
   ```

2. **开始筛选**

   点击「开始筛选」按钮，系统将从6大维度对输入的股票进行分析和筛选。

3. **查看筛选结果**

   筛选完成后，系统会显示符合条件的股票列表，按短期涨幅排序。

4. **查看详细分析**

   点击「详细分析」按钮，可以查看股票的详细信息、价格走势图、成交量走势图和风险提示。

## 分析维度说明

### 1. 短期涨幅
- **计算方法**：(当前价格 - 10日前价格) / 10日前价格 * 100%
- **筛选标准**：涨幅大于10%

### 2. 趋势强度
- **计算方法**：5日均线与10日均线的金叉状态、价格是否持续站在5日均线上方、短期均线斜率
- **筛选标准**：5日均线 > 10日均线，最近5个交易日中有4个交易日收盘价在5日均线上方，5日均线斜率为正

### 3. 量价配合
- **计算方法**：成交量放大倍数（与前5日平均成交量相比）、价格上涨时的成交量是否大于价格下跌时的成交量
- **筛选标准**：最近5日平均成交量比前5日平均成交量放大至少30%，价格上涨日的平均成交量大于价格下跌日的平均成交量

### 4. 资金流向
- **计算方法**：大单资金净流入（超大单+大单买入金额 - 超大单+大单卖出金额）、资金净流入率
- **筛选标准**：最近3个交易日资金净流入，资金净流入率大于5%

### 5. 行业热度
- **计算方法**：行业指数涨幅（与10日前相比）、行业内上涨股票数量占比
- **筛选标准**：行业指数涨幅大于8%，行业内上涨股票数量占比大于60%

### 6. 风险控制
- **计算方法**：波动率（最近10日标准差）、最大回撤（最近10日）、夏普比率
- **筛选标准**：波动率小于同期沪深300指数波动率的1.5倍，最大回撤小于15%，夏普比率大于0.5

## 风险提示

1. **短期涨幅过大风险**：短期涨幅过大的股票可能面临回调风险
2. **成交量异常风险**：成交量突然放大可能是短期资金炒作的结果
3. **行业轮动风险**：行业热度可能随时变化
4. **市场系统性风险**：大盘波动可能影响个股表现
5. **信息不对称风险**：公开数据可能存在延迟或不准确
